# Test fixtures

`oeisdata/` holds twelve `.seq` files from the [oeisdata](https://github.com/oeis/oeisdata) repository, laid out the way the atlas tool reads them and trimmed to the lines it parses: `%I`, `%S`, `%T`, `%U`, `%N`, `%O`, `%K`, and `%Y`.
